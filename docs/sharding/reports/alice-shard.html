hogd · database sharding

Where Alice’s data lives

The shard follows the record’s owner — never the names inside it.

An account is never split. All five of Alice’s own records share one shard, so anything about her alone is a single-shard read.

A hog transfer touches two. Alice’s shard and Bob’s — one each, because each balance is owned by its account.

A token never splits. Every holder’s slot is owned by the contract, so more shards cannot divide that ledger.
