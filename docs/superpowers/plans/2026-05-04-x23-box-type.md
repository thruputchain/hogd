# x23::Box<T> Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a non-nullable heap-allocated wrapper `x23::Box<T>` that enables recursive types without requiring `Ptr<T>` (nullable), plus x23c codegen support via `#[cpp(box)]` and `#[rust(box)]` annotations on `kPtr` fields.

**Architecture:** `Box<T>` is a `unique_ptr<T>` wrapper that is always non-null, serializes transparently as `T` (no presence flag), and forwards `T`'s `xdr_meta`, tuple protocol, and union protocol so the existing serializer/deserializer sees it as `T`. In XDR source, recursive fields still use `*` pointer syntax (required by the parser to avoid infinite struct size); the `#[cpp(box)]` / `#[rust(box)]` annotations on `kPtr` fields control whether the indirection is nullable (`Ptr`/`Option`) or non-nullable (`Box`).

**Tech Stack:** C++20 (concepts, constexpr), x23 serialization framework, x23c code generator, googletest

**Spec:** `docs/superpowers/specs/2026-05-04-x23-box-type-design.md`

```cpp
template<typename T> struct Box : private std::unique_ptr<T> {
  using super = std::unique_ptr<T>;
  using element_type = T;
  using value_type = T;

  Box() : super(new T{}) {}

  Box(const Box &other) : super(new T(*other)) {}
  Box(Box &&other) noexcept = default;

  Box(value_type t) : super(new T(std::move(t))) {}

  template<typename... Args>
  requires std::constructible_from<T, Args...>
  Box(std::in_place_t, Args &&...args)
    : super(new T(std::forward<Args>(args)...))
  {}
  template<typename U, typename... Args>
  requires std::constructible_from<T, std::initializer_list<U>, Args...>
  Box(std::in_place_t, std::initializer_list<U> ilist, Args &&...args)
    : super(new T(ilist, std::forward<Args>(args)...))
  {}

  Box &operator=(const Box &other)
  {
    **this = *other;
    return *this;
  }
  Box &operator=(Box &&other) noexcept = default;

  T *get() noexcept { return super::get(); }
  const T *get() const noexcept { return super::get(); }
  decltype(auto) operator*(this auto &&self) { return *self.get(); }
  auto operator->(this auto &&self) noexcept { return self.get(); }
};
template<typename T> Box(T &&) -> Box<T>;
```

struct BoxTree {
  int32_t value;
  x23::Ptr<BoxTree> left;
  x23::Ptr<BoxTree> right;

template<size_t I, x23::references<BoxTree> T>
requires (I < 3)
decltype(auto)
get(T &&t)
{
  if constexpr (I == 0)
    return (std::forward<T>(t).value);
  if constexpr (I == 1)
    return (std::forward<T>(t).left);
  if constexpr (I == 2)
    return (std::forward<T>(t).right);
}

template<>
struct std::tuple_size<BoxTree>
  : std::integral_constant<std::size_t, 3> {};

};

  static constexpr const char *type_name = "BoxTree";

  static std::optional<std::string> substring_removed(std::string_view str,
                                                      std::string_view sub)
  {
    auto i = str.find(sub);
    if (i != std::string::npos) {
      std::string str2{str};
      str2.erase(i, sub.length());
      return str2;
