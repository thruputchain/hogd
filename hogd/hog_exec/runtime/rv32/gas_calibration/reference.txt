# Checked by scripts/rv32_gas_check.sh. Costs are multiples of the

#
# That makes the file portable across IDENTICAL hardware, and not
# across microarchitectures. Measured: a reference taken on one
# cloud host failed 3 of 18 guards on another with the same engine
# fingerprint. The baseline is dispatch-bound and scales with core
# width and clock; a chained multiply or a pointer-chased load is
# latency-bound and does not, so their ratio is not invariant.
# Regenerate on the machine class the check will run on -- the
# calibration workflow's mode=reference does exactly that.
#
# Only cells at or above
# 1.0x baseline are guarded: a cell cheaper than
# the baseline instruction has no headroom worth watching.
#
# The tolerance is loose on purpose: this is a \"something is
# wildly out of whack\" alarm, not a performance budget. A guarded
# cell has to double relative to the baseline before it fires.
#
# Regenerating this file to make a failure go away hides exactly
# what it is for.
