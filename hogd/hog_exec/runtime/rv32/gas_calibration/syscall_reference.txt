#     > hogd/hog_exec/runtime/rv32/gas_calibration/syscall_reference.txt

# Or run the RV32 Gas Calibration workflow with mode=reference,
# which prints this block from the bench host.
#
# Checked by scripts/rv32_syscall_report.py --check. Costs are
# multiples of this run's own crossing cost, not nanoseconds, so
# the file survives the bench host changing speed. It does not
# survive changing microarchitecture: a syscall that waits on
# memory and one that only crosses the boundary do not scale
# together, which is the same reason the opcode reference carries.
#
# What this catches that the gas schedule cannot: the schedule's
# digest stops a CONSTANT being changed silently, and says nothing
# about the engine drifting away from the constants. A syscall that
# doubles in cost without any constant moving is exactly the
# failure that leaves contracts underpaying, and it is invisible
# to every other check in this repository.
#
# Regenerating this file to make a failure go away hides exactly
# what it is for.
